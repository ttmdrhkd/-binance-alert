· 텔레그램 전송은 브라우저 → 텔레그램 API 직접 호출 방식이라 네트워크/브라우저 환경에 따라 차단될 수 있습니다. 안정적으로 텔레그램만 받고 싶다면 기존 파이썬 스크립트를 백그라운드로 함께 실행하는 것을 권장합니다.
· 🔴 RSI 과매도 / 🟢 RSI 과매수 / 🟢🟢🟢🔴 3양봉+음봉 / 📊 거래량 급증은 이모티콘으로, 나머지 신호는 좌측 색상 바(초록=상승·빨강=하락·주황=터치)로 구분됩니다.
· 각 카드의 미니 차트는 해당 신호가 발생한 시간대의 최근 종가 흐름(최대 30개 캔들)입니다.
· ⚡ 바이낸스·업비트의 1분봉 변동성·1분/15분 RSI 알람은 WebSocket 실시간으로 판정합니다(업비트는 일봉 MA20 필터를 통과한 마켓만)(연결이 끊기면 스캔이 대신 확인). 나머지 알람은 설정한 주기의 스캔으로 확인합니다.
· 🟢 1시간봉 SFP(스윙 실패 패턴)는 마감된 1시간봉이 기존 스윙 저점을 꼬리로 이탈한 뒤 종가를 라인 위로 되돌릴 때 발생하며, 이후 6시간 동안 5분봉에서 🎯 2차 진입 타점을 감시합니다. SL=신호 캔들 저점, TP=바로 위 1시간봉 스윙 고점. 🔴 숏 SFP는 이를 좌우 반전한 것(바이낸스 전용: 스윙 고점 꼬리 돌파 후 종가 복귀, SL=신호 캔들 고점, TP=아래 스윙 저점).
· 🩸 OI 급감 + 긴 꼬리 / 💸 펀딩비 극단(±0.05%) + SFP·장악형 / 📈📉 OI·거래량 동반 급증은 바이낸스 선물 전용이며, OI는 1시간 단위 데이터를 직전 4구간과 비교합니다. 임계값은 코드 상단 OI_CFG에서 조정합니다.
· 📦 박스 리테스트: 최근 24개 1시간봉이 타이트한 박스(상·하단 각 2회 이상 터치)를 이룬 뒤 종가로 돌파/이탈하고, 12시간 이내에 경계를 다시 건드렸다가 돌파 방향으로 마감하면 알립니다. TP=박스 높이만큼의 측정 목표가, SL=리테스트 캔들 저점(숏은 고점). 조정은 BOX_CFG.
· 🔎 강세 스크리너는 클릭 시에만 실행되며(자동 반복 아님), 일봉 EMA99 위 · OI(미결제약정) 최근 추세 유지/증가 2가지를 모두 만족하는 바이낸스 선물 종목만 보여줍니다.
